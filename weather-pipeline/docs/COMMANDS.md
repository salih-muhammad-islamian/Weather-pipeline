# Git command cheat sheet

| Command | What it does |
|---|---|
| `git init` | start a repository in this folder |
| `git status` | what changed? |
| `git add .` | choose all changes for the next snapshot |
| `git commit -m "message"` | save the snapshot |
| `git log --oneline` | show the history |
| `git remote add origin URL` | connect to GitHub |
| `git push -u origin main` | upload (first time) |
| `git pull` | download the latest |
| `git switch -c name` | create and move to a new branch |
| `git merge origin/main` | bring main's changes into your branch |
